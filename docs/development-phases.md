# CartNova Development Phases

## Phase 0 — Architecture

Lock services, API boundaries, data ownership, events, gRPC contracts and concurrency points.

## Phase 1 — Go concurrency foundation

Study and run the examples in `examples/concurrency`.

## Phase 2 — Scaffolding

Repository, modules, configuration, Docker Compose and infrastructure.

## Phase 3 — User Service

Registration, login, JWT, roles and profiles.

## Phase 4 — Product Service

Products, categories, filtering and Redis caching.

## Phase 5 — API Gateway

Routing, authentication and public API boundary.

## Phase 6 — gRPC

Typed conceptual contracts in `proto/` and practical gRPC calls using protobuf Struct messages.

## Phase 7 — Order Service

Orders, transactions and lifecycle.

## Phase 8 — Kafka

Events, producers, consumers, topics and consumer groups.

## Phase 9 — Inventory + concurrency

Worker concurrency, channels, PostgreSQL locking and idempotency.

## Phase 10 — Notification + WebSockets

MongoDB notification history and live updates.

## Phase 11 — Full event-driven flow

Trace the complete order lifecycle across services.

## Phase 12 — Hardening

Validation, context, timeouts, retries, logging, graceful shutdown and security.

## Phase 13 — Testing

Unit, integration, API and concurrency testing plus the race detector.

## Phase 14 — Docker

Build reproducible service images.

## Phase 15 — AWS

Deploy the platform with practical managed infrastructure.

## Phase 16 — Documentation

Architecture, API, events, concurrency, deployment and design trade-offs.
